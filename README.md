# NYPD Hate Crimes: EDA

COMP714 Machine Learning, University of the Potomac. Author: Md Emon Ahmed. Instructor: Fuat Akal.

Exploratory data analysis (no models) of the NYC Open Data "NYPD Hate Crimes" dataset (4,575 rows, 14 columns).

- `NYPD_Hate_Crimes_EDA.ipynb`: executed notebook
- `NYPD_Hate_Crimes_EDA.pdf`: printout of the notebook
- `data/`: dataset and data dictionary

Run: `pip install -r requirements.txt && jupyter notebook NYPD_Hate_Crimes_EDA.ipynb`
